Мобильный доступ по Wi-Fi

      
      
Открывает доступ к LocalHarness с вашего смартфона или планшета по домашнему Wi-Fi. Сервер перезапустится автоматически и сразу покажет адрес и QR-код. Принимаются только приватные адреса (192.168.x, 10.x, VPN), публичный интернет закрыт. Пароля нет — не включай в общественных сетях.

      

        

          
          
        

        

      

    

    

      
Удалённый доступ из любой сети

      
      
ПК сам держит исходящее соединение с реле Cloudflare — белый IP и проброс портов не нужны. Приложение выдаёт временный код: введи его на сайте подключения, и LocalHarness откроется с любого устройства. Пока доступ включён, наружу пускаются только запросы с этим кодом.

Защита видеокарты (GPU Thermal Protection)

        опрос...
      

      
      
При нагреве GPU выше порога скорость генерации токенов плавно замедляется для охлаждения чипа. При критическом нагреве (100°C+) система предложит выгрузить модель из VRAM и подождать несколько минут.

Игровой режим и безопасность

      
      
При нажатии клавиши Escape или Pause во время выполнения игровых действий модель мгновенно отпустит все клавиши и передаст управление пользователю.

    

    

      

        
Проверка плагинов

        ключ не задан
      

      

        
        
      

      
Ключ с virustotal.com (профиль → API key). Даёт сверку SHA-256 с базой 70+ антивирусов. Без ключа плагины проверяет локальный аудит кода — файлы никуда не отправляются.
